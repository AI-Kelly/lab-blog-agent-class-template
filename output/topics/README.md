# Topic shortlists

Each time you type `/research-topics`, a shortlist of 10 ranked topics is saved here as `YYYY-MM-DD-topics.md`.

Under each topic is a line like this:

> Decision: [ ] approve [ ] reject. Reason:

Put an x in one box, for example `[x] approve`, and add a few words on why. The researcher reads your decisions on every run. It never suggests the same topic twice, and your reasons shape what it suggests next.
