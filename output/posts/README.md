# Finished posts

`/finish-post` saves each finished post here as two files:

- `YYYY-MM-DD-slug.html` – the post with its FAQ schema, ready to paste into your blog editor's HTML view
- `YYYY-MM-DD-slug-card.md` – the publishing card: title, meta description, URL slug, category, tags, image alt text, target keyword, the links in the post, and how to publish it

After the post is live, type `/mark-published <slug> <live URL>`.
