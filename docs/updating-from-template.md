# Getting updates from the class template

Your copy isn't linked to the class template, so new files from later sessions don't arrive on their own. When a new session's files are ready, ask Claude Code:

> Pull the latest files from the class template at https://github.com/AI-Kelly/lab-blog-agent-class-template into this repository. Add new files and update template files, but never overwrite anything in context/, output/, post-log.csv, or .env. Show me what changed before committing.

Claude Code will compare the two, bring in what's new, and leave your own business details alone.
