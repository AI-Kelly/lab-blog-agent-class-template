# Example posts

Save 3–5 of your best blog posts here. The writer agent studies them to match your voice.

**How to add them:** give Claude Code the links and ask:

> Save the text of these posts as Markdown files in context/example-posts/, one file per post.

**Pick posts that:**
- Sound most like you
- Performed well or got good feedback
- Cover different kinds of topics

Plain text is all that's needed. Images and page layout don't matter.
